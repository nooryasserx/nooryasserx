## Engineering principles

- Start with the product constraint and choose the smallest architecture that can meet it.
- Make contracts, authorization, failure modes, and observability explicit.
- Measure retrieval quality, latency, cost, and groundedness instead of relying on demos.
- Design integrations for retries, idempotency, reconciliation, and partial failure.
- Prefer maintainable systems over unnecessary complexity.
